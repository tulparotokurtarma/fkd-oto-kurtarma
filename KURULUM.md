# FKD Oto Kurtarma – GitHub Pages

Bu paket **9 orijinal fotoğrafı byte-for-byte korur**. Fotoğraflar assets klasöründedir.

**İçerik:** index.html, çekici-hizmeti.html, oto-kurtarma.html, hizmet-bolgeleri.html, arac-fotograflari.html, site.css, site.js, sitemap.xml, robots.txt, 9 fotoğraf.

**ÖNEMLİ: Bu zip henüz GitHub'a veya canlı siteye yüklenmemiştir.**

1. GitHub'da yalnız FKD için ayrı **public** repository oluşturun. Tercih edilen ad: `fkd-oto-kurtarma`. Tulpar dosyalarını kullanmayın.
2. Bu ZIP'i açın, içindeki dosya ve `assets` klasörünü **repository köküne** yükleyin. `README` GitHub'da ayrıca görüntülenebilir.
3. GitHub Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Yayımlanan `https://KULLANICI.github.io/fkd-oto-kurtarma/` adresinde **5 HTML sayfasını ve 9 fotoğrafı** test edin.
5. Sitenin yeni adresi çalışmadan eski ChatGPT Sites bağlantısını ve alan adı kayıtlarını SİLMEYİN.
6. Sonraki aşamada `fkdotokurtarma.com.tr` için GitHub Pages Custom domain ve DNS kayıtları yapılacak. Bunun için ayrı karar ve onay gereklidir. Önceden CNAME dosyası eklemek staging URL'yi bozabilir, bu nedenle **CNAME-KURULUMDA-EKLENECEK.txt** yalnız not olarak bırakıldı.
7. Alan adı GitHub'a alındıktan sonra siteyi Google AdsBot dahil test edip Google Ads onayını yeniden kontrol edin. Barındırma değişimi “Çalışmayan hedef” hatasını gidermeyi garanti etmez.
